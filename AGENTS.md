# Directrius per a Agents — Hostal Somnis

## Git & Versioning
- **Commit i Push automàtic**: Sempre que es completi un canvi, refactorització o correcció en el codi, s'ha de fer `git commit` amb un missatge descriptiu en català/anglès i `git push origin main` immediatament perquè el repositori remot de GitHub estigui sempre al dia.
- **Identitat Git**: Utilitzar la configuració del projecte (`Hostal Somnis <somnis@hostal.local>`).
